# 1.1.1 开发计划

> 本分支从 `release/1.1.0-tomato-reader` 创建。1.1.0 未完成的功能统一转入本版本，不回填到 1.1.0。

## 版本原则

- 继续使用本仓库作为唯一代码仓库，所有开发、代码审查、CI 构建和预发布均在 GitHub 完成。
- 不另建项目，不要求用户自行部署模型或维护服务器。
- 优先真正免费、长期可用的方案；不接入按量收费 API，也不把试用额度或有限免费额度称为永久免费。
- App 端使用在线 AI 服务，不把在线听书改成本地离线模型。
- 不要求用户绑定银行卡、信用卡或任何付款方式；不允许潜在超额扣费。
- 版本交付方式：不单独发布开发预览版；1.1.1 完成全部验收后直接正式发布。

## 从 1.1.0 延期的功能

### 在线 AI 多角色听书
- 在线 AI 语音合成服务选型与可用性验证。
- Azure AI Speech F0 曾作为首选候选调查，但用户明确拒绝绑定银行卡/信用卡；因此**不采用 Azure、不要求用户注册 Azure、不将 Azure 作为当前实施候选**。除非未来微软提供无需任何付款方式即可注册并且无超额扣费风险的独立免费方案，否则不重新考虑。
- 在线服务必须同时满足：无需绑定任何付款方式、无需自建/维护服务器、无需订阅或按量付费、超额后硬停止而非产生费用、支持中文自然语音和可配置多角色音色、支持长章节分段与音频输出。
- 任何仅有试用额度、需要信用卡验证、必须启用结算账户、超额可扣费的服务均直接排除，不进入 App。
- 小说剧情上下文分析、人物识别、旁白与对白区分。
- 已新增保守型对白分段原型：识别常见中文引号对白及附近明确的“某某说道/问道”等说话提示；只有角色已配置音色引用时才生成 speaker 标记，无法确认的角色不猜测，回退为未分配角色文本。该规则不是 AI 剧情理解，复杂指代、跨句角色推断和情绪判断仍未实现。
- 人物音色分配及跨章节一致性。
- 情绪、语气、语速和停顿控制。
- 长章节分段合成、连续播放、缓存和失败恢复。通用音频播放层已增加 WAV/MP3 格式入口，保留 Kokoro 现有 WAV 调用兼容；在线服务接入后可复用后台播放与锁屏控制。已先将通用分段器改为按 Unicode 字符计数，避免在线合成分段时拆坏 emoji/扩展字符。
- 已增加 Fish Audio API 客户端适配层作为早期技术原型：明确请求 `s2.1-pro-free`，请求 MP3，并支持 `reference_id` 多音色数组；对 401/402/429 和空音频返回明确错误，不允许静默回退到付费模型。该适配层尚未接入播放器，也未完成真实 API 试听；Fish 免费开放期当前公布截至 2026-11-30，不作为长期生产候选。
- 若找不到符合免费、安全和长期可用要求的在线服务，必须如实说明，不得以本地部署或收费接口替代用户要求。

### 听书播放器重构
- 参考番茄小说的交互体验重新设计播放器（不复制其专有代码或素材）。
- 播放/暂停、上一章/下一章、进度、倍速、定时关闭、章节目录。
- 后台播放、播放状态记忆、缓存和连续章节播放。

### Kokoro 清理
- 在在线 AI 替代方案验证并接入后，移除 Kokoro 模型、原生推理、模型下载管理、专属配置和补丁。
- 保留通用音频播放能力。
- 不在替代方案尚未可用时贸然删除现有代码。

### 在线更新完善
- 核查并确定免费、可持续的更新服务方案。
- 验证更新检查、下载、应用和失败回退。
- 明确 OTA 仅覆盖兼容 runtime 的 JS/资源更新；原生代码或依赖变化仍可能需要重新自签安装。

## 验收与发布要求

- 不把技术调研或 UI 占位视为功能完成。
- 在线 AI 必须有真实可用的服务和中文多角色试听结果。
- 更新功能必须在实际安装的自签版本上验证。
- CI 构建产物仅用于内部验收，不创建开发预览 Release。
- 所有关键测试、iOS unsigned IPA 构建和实际功能验收通过后，直接正式发布 1.1.1，不另行询问是否发布预览版。

## 长期免费在线服务的硬性门槛（新增）

1. 生产默认服务必须有公开、可核验的长期免费条款；不得依赖活动赠送、试用期、开发者预览期、个人账号每日 GPU 配额或社区共享算力。
2. 必须明确免费调用上限、速率限制、排队规则、商用/个人使用范围、数据留存政策和停止服务时的处理方式。若有硬额度，必须在 UI 中如实展示并在耗尽后停止，不得自动切换付费模型。
3. 必须支持中文自然语音、可配置多角色音色、长章节分段与 MP3 输出；仅有开源权重不算在线服务。
4. 不把 GitHub Actions、临时公共 Demo、Hugging Face ZeroGPU 或任何免费 GPU 队列当作生产后端。
5. 不要求用户自建/维护 NAS、电脑或云服务器；不要求用户绑定银行卡/信用卡或承担潜在超额账单。
6. API Key 不能写入仓库、日志或普通偏好存储。客户端 Keychain/Keystore 也不能视为防逆向提取；必须评估密钥风险。若服务需要项目级密钥，必须有不产生用户费用、可持续安全运营的后端。
7. 若市场上不存在同时满足以上条件的在线服务，则明确标记“在线永久免费方案不可用”，保留可替换的服务适配层，不接入不合格服务，不删除 Kokoro 现有实现，也不谎称功能已完成。

### 当前技术调研结论（2026-11-22）

- Azure AI Speech F0：**排除**。虽有每月免费额度和中文多音色，但开户可能要求绑定付款方式；用户明确不接受绑定银行卡/信用卡，因此不作为候选。
- **SpeechifyAI API Free：新增优先验证候选**。官方当前定价页列出每月 50,000 个 TTS 字符、无需信用卡、免费额度硬停止、不会超额自动扣费，并宣称支持 1,500+ 音色和 30+ 语言；但中文需要使用其旧版 Simba 1.6 多语言模型，官方将其标记为 legacy。必须验证中文普通话音色、不同 voice_id 角色切换、免费层 API 实际权限、账户注册是否无需任何付款方式，以及硬额度耗尽行为。免费层额度远低于长篇小说需求，不能称为无限或永久保障。
- **Google Gemini TTS Free Tier：新增研究候选**。官方价格页将 Gemini TTS 列入免费层，但免费层内容可能用于改进 Google 产品；多角色 TTS 有近期用户报告的说话人串音/长音频音色漂移问题。还需核验 AI Studio API Key 是否无需绑定付款方式、准确速率/每日配额、超额后是否硬停止，以及隐私条款。未通过前不接入。
- Fish Audio S2.1 Pro Free：仅短期候选，免费开放期当前公布至 2026-11-30，不满足长期条款。
- Cloudflare Workers AI：每日免费 Neurons 有限，超额进入付费计划；已查到的 MeloTTS 计划弃用日期为 2026-11-20，不能作为当前稳定候选。发现其他无需付款方式的新模型时可重新评估。
- Hugging Face ZeroGPU：免费账户每日 GPU 配额仅 5 分钟，属于共享算力配额，不满足连续听书生产需求。
- CosyVoice / MOSS-TTS 等开源模型：权重许可不等于免费托管，在线推理仍需持续算力，不符合“不让用户部署、无服务器费用”的约束。

当前没有批准的在线生产服务。下一步优先实测 SpeechifyAI Free 的中文音色与硬额度行为，并核验 Google Gemini TTS Free Tier 的无付款方式条件、隐私和多角色稳定性。任何候选都必须无需付款方式、超额硬停止；通过真实中文多角色试听和设备连续播放验收后才允许接入。未通过前保留 Kokoro 现有实现。


### 官方文档复核补充（2026-11-22，以下内容优先于上方旧结论）

**Speechify 模型与中文支持出现了重要更新：**

- 不再把 Simba 1.6 当作新账户的中文方案。官方说明旧模型 ID 已退休；新集成推荐 `simba-3.5`，覆盖 48 种语言，包含中文 `zh`，并且目录中的音色均可用于该模型。中文音色目录列出 `xubai`、`yanchuan`、`tinglan`、`nanxu` 等候选。实际可用列表必须以新账户 `GET /v1/audio/models` 和 `GET /v1/voices?locale=zh-CN&model=simba-3.5` 的返回为准。
- 标准 TTS 可按每段请求切换 `voice_id`，因此可尝试用不同角色音色分段合成；但 Speechify 的独立 Dialogue 模型目前仅支持英语，不能把它描述成中文原生多说话人对话模型。中文角色切换需要客户端先完成人物/对白分配，再逐段请求普通 TTS。
- Simba 3.5 支持中文及流式长文本接口，单次 stream 最多 20,000 个口播字符；免费档 API 速率为每秒 1 次、并发 1 个请求。长章节必须串行/限速处理，并实现中断恢复。
- Simba 3.5 的 SSML 可用于停顿、语速和别名读音；官方说明 pitch、volume、emotion 标签虽然接受但不会实际应用。因此不能承诺模型能按剧情自动演绎愤怒、悲伤等情绪。
- **免费额度的官方页面存在冲突，暂不确认具体数字**：定价子页面显示 50,000 字符/月；官网首页近期搜索结果显示 500,000 字符/月，并提到 Simba 3.5 在 2026-11-21 前后的额度调整。必须以登录后控制台实际显示和首次免费账户实测为准；在核实前按较低的 50,000 字符估算，不宣传 500,000 已确认。
- Speechify 的免费计划页面仍明确标注无需信用卡、免费余额耗尽暂停且不能 top-up；但正式接入前仍须确认新账户创建流程没有要求任何银行卡/信用卡，并验证免费层额度耗尽确实返回停止状态。

**当前判断：Speechify Simba 3.5 升级为首要实测候选，但仍未批准接入生产。** 需要实测新账户无付款方式注册、免费模型/中文音色实际权限、两种以上中文音色连续切换、20,000 字符分段、MP3 输出、1 req/sec 限速、免费额度耗尽硬停止，以及数据留存/商用条款。任何一项不合格都不接入。

**Gemini TTS 补充：** 官方定价页确认 Gemini TTS 免费层内容会用于改进 Google 产品；免费层不适合作为默认隐私敏感小说服务。仍需核验 API key 创建和免费配额的无付款方式条件；不允许开启付费账单或自动扣费。

**CI 修复记录：** 2026-11-22 最近一次 unsigned IPA workflow 在 `test:speech-credentials` 失败，原因是 Node 单元测试加载 `expo-secure-store` 时触发原生模块导入错误。已将 `src/speech-credentials.ts` 改为延迟加载原生 SecureStore，使注入 mock 的单元测试无需加载原生模块。修复提交后必须重新跑完整 workflow；在新 workflow 通过前，不得宣称 IPA 已构建成功。
