# 1.1.2 开发计划：别名源完善与 Kokoro 清理

## 版本范围

- 基于 1.1.1 已验收代码继续开发，不另起项目，不做无关重构。
- 保留现有 10 个正文书源，不为别名功能改写或删除它们。
- 保留第 11 个独立别名源：完整动态导入，多条别名映射多本小说，归一化、冲突检测和订阅更新同步。
- 用户输入别名后先解析为真实书名，再交给已启用的正文源搜索；别名库不提供正文，也不计入正文源数量。
- 彻底删除 Kokoro / Sherpa-ONNX 相关运行时代码、依赖、模型下载器、音色目录、原生补丁、构建工作流、服务端和界面入口。
- 不引入收费 TTS、要求绑定银行卡的服务或 iPhone 系统朗读。Gemini 仅保留手动试听实验，不作为正式朗读引擎。

## 实现与验收

- [x] 别名源作为第 11 个独立订阅条目导入。
- [x] 全量别名数据动态下载，不将当前样本硬编码进 App。
- [x] 多别名、多小说记录导入，规范化匹配。
- [x] 冲突别名不静默选择，冲突项排除并显示统计。
- [x] 订阅更新按完整快照同步正文源和别名映射。
- [x] 别名命中后用真实书名搜索现有正文源。
- [ ] 删除 Kokoro / Sherpa-ONNX 全部运行时和工程残留。
- [ ] 清理旧朗读设置与专属缓存，不触碰书架、阅读进度、订阅源和本地导入文件。
- [ ] 运行完整 TypeScript、功能、书源和依赖安全检查。
- [ ] 构建并检查 1.1.2 未签名 iOS IPA，确认 production OTA URL、channel 和 fingerprint runtime。
- [ ] 发布 1.1.2 正式 GitHub Release。
- [ ] 发布 1.1.2 Production OTA，并为已安装的 1.1.1 / 1.1.0 运行时发布兼容更新。

## 数据安全边界

清理不得删除用户书架、阅读历史、阅读进度、阅读设置中的非朗读字段、书源订阅、别名映射或用户导入的 TXT 文件。旧设置中的 Kokoro 音色字段会被新设置规范化逻辑忽略并在下次保存时自然清除。
