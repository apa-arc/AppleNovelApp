# v1.1.5 开发计划

基于 v1.1.4 主线创建独立开发分支 `release/1.1.5`。本版本先完成需求实现与测试，不在功能验收前发布 Release 或 OTA。

## 已确认需求

1. 完善书架与搜索结果封面：补齐可从书源数据提取的封面 URL；图片加载失败时提供明确的封面占位，不显示空白。
2. 书架显示切换：网格 3×3 与列表两种模式，通过按钮切换，并持久化用户选择。
3. 删除听书模块：移除阅读器听书入口、设置界面、播放控制、TTS API/语音角色试听及不再使用的代码和依赖；不影响普通阅读。
4. 章节预缓存：在线阅读当前章节时，在后台预取后续 5 章；优先命中缓存，缓存按小说/章节隔离，不阻塞当前阅读，失败时可重试。
5. 阅读菜单：移除独立 Aa 设置按钮，点击阅读内容中心区域显示/隐藏阅读菜单。
6. 翻页方式：左右滑动、上下滚动、仿真翻页、覆盖翻页、无动画翻页；选择持久化，切换不得丢失阅读进度。
