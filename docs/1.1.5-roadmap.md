# v1.1.5 开发计划

基于 v1.1.4 主线创建独立开发分支 `release/1.1.5`。本版本先完成需求实现与测试，不在功能验收前发布 Release 或 OTA。

## 已确认需求

1. 完善书架与搜索结果封面：补齐可从书源数据提取的封面 URL；图片加载失败时提供明确的封面占位，不显示空白。
2. 书架显示切换：网格 3×3 与列表两种模式，通过按钮切换，并持久化用户选择。
3. 删除听书模块：移除阅读器听书入口、设置界面、播放控制、TTS API/语音角色试听及不再使用的代码和依赖；不影响普通阅读。
4. 章节预缓存：在线阅读当前章节时，在后台预取后续 5 章；优先命中缓存，缓存按小说/章节隔离，不阻塞当前阅读，失败时可重试。
5. 阅读菜单：移除独立 Aa 设置按钮，点击阅读内容中心区域显示/隐藏阅读菜单。
6. 翻页方式：左右滑动、上下滚动、仿真翻页、覆盖翻页、无动画翻页；选择持久化，切换不得丢失阅读进度。

## 当前代码检查发现

- 书架已有 `shelfView` 状态和网格样式，但启动加载时被强制设为 `grid`，没有切换按钮；列表模式的渲染也尚未独立实现。
- 阅读器目前只有 `scroll` / `tap` 两种阅读方式，中心点击会显示/隐藏阅读控件，但底部仍有 Aa 按钮。
- 在线章节切换直接请求书源正文，没有章节缓存或预取队列。
- 阅读器仍保留 Gemini TTS 相关设置、试听、朗读和播放代码，需要完整清理。
- 搜索解析已支持常见封面字段与部分 HTML 懒加载属性，但仍有封面字段/属性覆盖不足的问题；需扩展解析并添加测试，不能凭猜测补造封面地址。

## 验收要求

- 网格与列表来回切换、重启后保持选择。
- 搜索结果与书架封面优先显示真实封面；无可用封面时显示非空占位。
- 听书入口、弹窗、播放控制和相关 Key 设置均不存在。
- 在线阅读章节时后台最多预取后续 5 章；缓存键包含小说和章节身份，切换书籍不会串章；缓存命中优先。
- 中心点击可显示/隐藏阅读菜单；不再显示独立 Aa 按钮。
- 五种翻页方式均可选择、可保存；翻页/切换方式后章节与段落进度正确。
- 运行 TypeScript 检查、完整自动化测试和 iOS 未签名 IPA 构建；IPA 使用 SideStore 兼容打包流程。
