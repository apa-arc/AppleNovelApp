# v1.1.6 开发计划

基线：v1.1.5 正式版。开发分支：`v1.1.6-dev`。本分支只做开发与验证，不自动发布正式 Release 或 Production OTA。

## 已确认需求

### P0：搜索性能与质量
- 多书源有限并发，默认并发 3；每个书源完成后立即合并并展示结果，不等待全部书源。
- 书源请求沿用超时保护；慢源不能阻塞已返回结果。
- 搜索支持取消/替换：新搜索启动后，旧搜索的迟到结果不得覆盖新结果。
- 记录书源响应耗时、成功/失败和结果数，持久化性能统计，优先调度快且稳定的书源。
- 书名精确匹配优先，其次前缀/包含/模糊匹配；别名映射继续保留。
- 多源结果合并去重，匹配质量排序与源延迟排序分离。
- 补充并发、乱序返回、取消、模糊匹配和统计更新测试。

### P1：番茄官方音频技术验证
- 研究 fqdt 的官方 AI/真人音频获取流程，仅通过允许使用的方式验证公开可用性。
- 验证书籍/章节映射、音频格式、音频 URL 生命周期、播放授权和 iOS 播放兼容性。
- 验证通过前不承诺所有小说都可获取，不把未经授权的内部接口或受保护资源接入产品。

### P1：听书 UI 与播放器
- 听书主页面参考用户提供的番茄智能朗读截图，采用本软件自己的视觉样式。
- 阅读页胶囊悬浮播放器：封面、播放/暂停、设置、关闭；可拖动，避免遮挡正文。
- 点击悬浮播放器设置按钮后弹出听书设置面板；不另设独立设置入口。
- 设置项：定时关闭、语速、可用音色、音频预加载。
- 支持章节连续播放、进度记忆、后台/锁屏播放；耳机控制列为兼容性验证项。

### P2：TTS 兜底
- 官方音频不可用时再评估免费开源 TTS。
- 多角色识别失败或人物不明确时回退默认语音，不中断播放。
- 优先验证 iPhone 本地离线方案，不把免费额度云 API 当作永久免费方案。

## 版本与发布约束
- package.json、app.json 版本统一更新为 1.1.6，待功能验收后再做。
- 保持 `updates.checkAutomatically = NEVER`，保留手动更新，不增加自动更新行为。
- 正式版 IPA 必须走 SideStore 兼容的未签名打包流程。
- Production OTA 只在用户明确确认发布时从 main 分支手动发布；开发分支不得触发生产 OTA。
- 完成 TypeScript、完整自动化测试、iOS 构建与 IPA ZIP 完整性检查后，才进入发布步骤。
