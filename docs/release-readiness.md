## 当前功能边界

- App 在线书源运行时支持受限 HTTPS JSON 接口和声明式 CSS HTML 规则；不执行上游 JavaScript。
- HTML 解析支持常用标签、ID、class、属性、后代/子代组合、逗号分组及 first/last/nth-child；未支持的选择器会明确报错，不会静默忽略。
- XPath、正则替换、JavaScript 规则、动态加载内容及复杂 Legado 脚本不能直接运行。
- 当前订阅包含 10 个正文源和 1 个独立别名源。别名库只将别名映射为真实书名，再由正文源搜索；不提供正文，也不计入正文源数量。
- Kokoro / Sherpa-ONNX 离线引擎及其模型、下载器、原生插件、服务端已从 1.1.2 移除。Gemini TTS 仅是手动试听实验，不接入章节连续朗读，不作为生产朗读方案；不会使用 iPhone 系统语音。
- OTA 通过 Expo Updates 下发普通界面、业务逻辑和 JS 资源；原生模块、权限、底层依赖或 iOS 原生配置变更仍需重新构建并安装 IPA。
- 正式安装包启动和回到前台时自动检查更新，发现更新后后台下载，用户确认重启时应用更新。

## 真机验收顺序

1. 首次启动、切换四个主页面，重启后书架和阅读记录仍在。
2. 导入/停用/删除 JSON 书源，验证非法 HTTP、内网地址和跨域跳转被拦截。
3. 导入当前 11 条订阅，确认 10 个正文源和 1 个别名源分别识别。
4. 使用别名样本“五月轮回”搜索，确认解析为真实书名“斗罗：武魂菩提树，唐三魔王护”，再由正文源搜索。
5. 验证冲突别名不会误映射，订阅更新会同步增删别名。
6. 加入书架、切换章节、退出重进，验证阅读位置。
7. 调整字号、主题、行距和翻页模式，验证重启后设置保留。
8. 验证 Gemini 试听实验只在用户手动提供 Key 时运行，关闭 App 后 Key 不保留；不启用付费结算。
9. OTA 只向平台与 fingerprint runtime 匹配的安装包提供更新；原生依赖变更必须安装新 IPA。

## 数据保护

清理旧 Kokoro 代码时不得删除用户书架、阅读记录、阅读进度、订阅源、别名映射或导入的小说文件。新版本阅读设置规范化时会忽略旧 Kokoro 音色字段，仅保留阅读器设置。
